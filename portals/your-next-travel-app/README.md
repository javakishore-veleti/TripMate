# Your Next Travel portal

Angular 21 SPA for Your Next Travel. FastAPI is a separate API process.

```bash
npm start
```

Dev server: `http://127.0.0.1:4200`  
Proxies `/api` and `/health` to `http://127.0.0.1:8000`.

From the repo root, `npm run local:app-run` starts the API (schema upgrade included) and this portal together.
