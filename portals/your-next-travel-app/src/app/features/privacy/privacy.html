Privacy

This copy runs on your machine — or your cloud.

Your Next Travel is software you download (GitHub or a container image) and run yourself. The authors do not host your account, prompts, or API keys.

Who holds the data

Whatever this instance stores stays in the database and files you configured (SQLite under runtime-data/local-deploy/ by default, or your own Postgres). If you run it only on a laptop, that is local. If you deploy the same image on your cloud, that host is yours. We do not receive a copy.

What this instance can store

Explore does not require an account. If you sign up here, this instance keeps email, display name, a password hash, traveler preferences, session or JWT records, and the prompts and plans you generate. Access logs on your machine or cloud may include an IP address.

Your keys, not ours

Cloud model keys, optional flight-data keys, and similar secrets belong to you. You put them on the machine you run (environment variables, or a Settings vault locked with a passphrase you remember). The authors never see those keys. If you forget a vault passphrase, encrypted secrets are gone; base settings (provider, model, local Ollama URL) stay, and you enter new keys.

Who else may see a prompt

If you pick a cloud model host (for example Groq), that provider receives the prompt and any preference text this instance sends. A local Ollama model stays on the machine you pointed at. Destination photos load from Unsplash. Optional live flight APIs receive the route you search. Each of those services has its own terms.

If you put this on a public URL

You become the operator of that URL. Privacy law (including GDPR) can apply to you if other people create accounts there. This page is not legal advice and does not make a public deploy compliant.

Your choices on this instance

Edit preferences, sign out, delete the account in this database, or wipe the data directory / database volume. Deleting an account here does not erase prompts already sent to a model or flight provider.

This is a learning project, not a travel agency. Do not put health, payment cards, or government ID into prompts or notes.
